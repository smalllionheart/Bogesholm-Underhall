# Objektmodell

Denna katalog beskriver den gemensamma modell som används när register skapas eller utökas. Den är inte ett register över faktiska objekt och innehåller därför inga inventeringsuppgifter.

[`objektmodell.yaml`](objektmodell.yaml) anger gemensamma fält, värdemängder, relationer och regler för historik. Kategoriregister får ha ytterligare fält när de är relevanta för objektets typ, men ska behålla de gemensamma fälten när informationen finns.

Använd öppna, läsbara format: YAML för register och modell, CSV för enkla inventeringsunderlag och Markdown för förklaringar. Länka till dokument i SharePoint i stället för att lägga originaldokument i repot.
