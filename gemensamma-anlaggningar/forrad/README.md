# Förråd

Register över förråd och gemensamma förrådsutrymmen.

## Register

- [`register.yaml`](register.yaml) – maskinläsbart register över förråden.

## Källa

Uppgifterna är importerade från `Förråd_garagelista 2026-02-25.xlsx`, uppdaterad 2026-02-25.

Registret innehåller 78 lägenhetsanknutna förråd samt gemensamma eller ännu inte klassificerade förråd som framgår av underlaget.

### Datakvalitet

Förråd 610 och 611 finns numrerade i underlaget, men någon tillhörighet eller förrådstyp framgår inte. De är därför markerade som `preliminär` och ska inte behandlas som verifierad information.
