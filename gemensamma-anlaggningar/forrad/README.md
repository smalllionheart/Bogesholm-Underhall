# Förråd

Register över förråd och gemensamma förrådsutrymmen.

## Register

- [`register.yaml`](register.yaml) – maskinläsbart register över förråden.

## Källa

Uppgifterna är importerade från `Förråd_garagelista 2026-02-25.xlsx`, uppdaterad 2026-02-25.

Registret innehåller 78 lägenhetsanknutna förråd samt de gemensamma förråden 609 och 629.

### Datakvalitet

Förråd 610 och 611 förekommer endast som `N/A` i källunderlaget och ingår inte som aktiva objekt. Den osäkra historiska uppgiften bevaras i registerfilens `historisk_notering`; inga objekt ska skapas för dem utan nytt historiskt underlag.
