## Dokumentationsprincip

Varje hus dokumenteras som ett eget objekt och fungerar som överordnad nivå för objekt som hör till byggnaden.

Exempel:

`Hus 57 → Lägenhet 57-01 → Dörr D57-01`

En byggnads dokumentation kan innehålla:

- Objekt-ID
- Husnummer
- Adress eller placering, när relevant
- Byggnadstyp
- Byggår, om känt
- Omfattning och grundläggande byggnadsuppgifter
- Aktuell status
- Underhållshistorik
- Relaterade tekniska installationer
- Relaterade byggnadsdelar
- Relaterade lägenheter
- Hänvisningar till originaldokument

Uppgifter som ännu inte är verifierade ska inte presenteras som fakta.
